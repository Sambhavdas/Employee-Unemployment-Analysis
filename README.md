# 📊 Employee Dashboard Analysis

## 📌 Project Overview

This project presents an analysis of employee and unemployment-related data using **Microsoft Excel**.

The project focuses on identifying trends, comparing unemployment rates, and analyzing differences across gender, areas, and years. The insights are presented through an interactive dashboard and project presentation.

---

## 🎯 Project Objectives

* Analyze unemployment rates over different years
* Compare Male and Female unemployment rates
* Identify areas with the highest and lowest unemployment rates
* Analyze unemployment trends over time
* Understand the gender gap in unemployment rates
* Present key insights through data visualization

---

## 🛠️ Tools Used

* **Microsoft Excel** – Data Cleaning, Data Analysis & Dashboard
* **PowerPoint** – Project Presentation
* **GitHub** – Project Portfolio & Documentation

---

## 📊 Dashboard

The dashboard provides a visual overview of the analysis, including:

* Average Unemployment Rate
* Maximum & Minimum Unemployment Rate
* Year-wise Unemployment Trend
* Male vs Female Comparison
* Area-wise Unemployment Rate
* Gender Gap Analysis
